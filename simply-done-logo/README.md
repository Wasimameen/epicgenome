# Simply Done logo (vector)

Vector recreation of the Simply Done "No Mess. No Stress." logo.

| File | Use |
|---|---|
| `simply-done-logo.svg` | Master editable vector (Illustrator, Inkscape, Figma, Affinity, Canva) |
| `simply-done-logo.pdf` | Vector, opens editable in Illustrator; print shops |
| `simply-done-logo.eps` | Vector, legacy print / sign / embroidery vendors |
| `simply-done-logo-4000px-transparent.png` | High-res raster, transparent background |
| `simply-done-logo-4000px-white.png` | High-res raster, white background |

## Layers (SVG group ids, bottom to top)

| Layer | Color |
|---|---|
| `shadow-gray` | `#5A585D` |
| `white` | `#F1F2F6` |
| `light-gray` | `#C9C9D1` |
| `pink-dark` | `#8E1450` |
| `pink` (brand pink) | `#FC1560` |
| `black` | `#121111` |
| `glints` | `#FFFFFF` |

Recolor a whole layer by changing the `fill` on its group. Text is outlined
(converted to shapes), so it scales cleanly and needs no fonts. The closest
matching typeface for edits is **Montserrat** (Bold/ExtraBold).
