# Awesome Attorneys — "40% At Fault"

A cinematic 16.5s motion-graphic spot in [Remotion](https://remotion.dev).
Everything is vector, CSS, SVG and light — no stock footage, no photos —
so it renders crisp at any size.

Deliverables and the handover notes live in **[`out/README.md`](out/README.md)**
(generated). This file is about the code.

## Quick start

```bash
npm install
npm run assets        # assets-in/ -> public/, writes src/assets.ts
npm run transcribe    # whisper.cpp -> src/timing/vo-words.json
npm run studio        # preview
npm run render        # all six videos + both thumbnails
```

On a headless box, point Remotion at a Chrome headless shell:

```bash
export REMOTION_BROWSER=/path/to/chrome-headless-shell
```

## The one idea to understand

**Nothing is timed in frames.** `src/timing/beats.ts` looks every sync
point up *by word* from the Whisper transcript, and the composition's
duration is `t.end + 2.6s`. Drop in a new `vo.mp3`, re-run
`npm run transcribe`, and the entire spot — including its length —
re-times itself. No component holds a frame number.

`LEAD = 3` frames: every visual hit and every SFX fires three frames
*before* its word. Sound and picture slightly anticipate speech; that is
what makes the sync feel tight.

### Two structural decisions worth knowing

**Beats 1 and 2 share one `<Sequence>`.** Beat 2 does not replace beat 1's
frame, it transforms it — the stamp that lands on "forty" is the same
element that gets struck through on "opening" and shatters on "not".
`useStampState()` is the single registration point, so `StrikeThrough`
and `Shards` can never drift out of alignment with the stamp.

**Beat 3 mounts *behind* the cold act.** The transition is a light sweep,
not a dissolve: the warm scene is already in place, and the cold scene is
masked away along the sweep's own edge (`sweepCutoutMask`). Beat 3's
horizon line carries the exact inverse mask (`sweepRevealMask`) so beat
2's gold rule and beat 3's horizon — the same line under two different
cameras — hand over under the band instead of doubling.

The beat 3 → 4 change is a hard cut, so those two never overlap.

## Modes

`mode: "overlay"` renders no background, no texture and no audio, and
switches every piece of type to a two-part shadow with a tight contact
layer so it stays readable over unknown B-roll. The horizon *fills* (sun
disc, ridge silhouettes) survive; the sky gradient behind them does not.

`aspect` swaps layout tokens only — there is no second copy of any
component. `layout.safe.sideCam` is the safe margin pre-shrunk by the
largest camera scale in the spot, so a clamped element stays inside the
safe area even at full push.

## House rules

- Drive everything from `useCurrentFrame()` — never CSS transitions or
  animations, never timers.
- Entrances are overdamped springs; exits use expo easing. Two deliberate
  exceptions carry overshoot: the stamp impact and the two CTA slams.
- Reveals are mask wipes with a compound transform. Nothing arrives on
  opacity alone.
- Deterministic only: `random(seed)`, never `Math.random()`.
- Fonts load from `public/fonts` via `@remotion/fonts`, not from
  fonts.gstatic.com — a render must not depend on the network.
